# 🎬 Отправь своё видео на стрим Forzes!

Хочешь, чтобы **Forzes** посмотрел твоё видео в прямом эфире? Всё просто: заполни форму — и стример увидит твоё видео прямо во время стрима!

**Ссылка на сайт:** смотри в описании канала / закрепе в чате стрима.

## 📺 Как отправить видео

1. Открой сайт по ссылке выше
2. Впиши **свой ник** — как тебя зовут в чате или на канале
3. Вставь **ссылку на YouTube-видео** (подойдут обычные видео и Shorts)
   - пример: `https://youtu.be/dQw4w9WgXcQ`
4. Напиши **описание** — о чём видео и почему стоит его посмотреть
5. Нажми **«🚀 Отправить на обзор»**
6. Готово! Как только ссылка распознается — сразу появится превью видео ✅

Между отправками — минута паузы, не спамь :)

## 📏 Правила

- ✅ Ссылки — только на YouTube (обычные видео и Shorts)
- ✅ Проверь, что видео открывается по ссылке (не приватное, не удалённое)
- 🚫 Не спамь: одинаковые и пустые заявки удаляются
- 🕐 Видео смотрят по очереди — терпение, и твоё тоже засветят 💜

## ❓ Частые вопросы

**Отправил, а превью не появилось?**
Проверь, что ссылка ведёт прямо на видео YouTube и открывается в браузере.

**Мою заявку удалили — почему?**
Ссылка была битой/приватной или заявка была спамом.

**Можно отправить несколько видео?**
По одному за раз, между отправками — минута.

**Когда посмотрят моё видео?**
Во время ближайшего стрима. Следи за эфирами!
